# AgentHub v0.1.5-patch.2

程序版本保持 `0.1.5`。本次补丁标签用于构建；临时安装包在 Actions 下载，保留 14 天，需要登录 GitHub。

## 已实现

- 能力库新增本地 Skill 文件夹导入：预览完整文件与运行目录排除项，重新校验后原子导入；保留扫描导入入口。
- 版本记录支持逐项选择 Skill、MCP、规则和插件；保存前审查所选能力、排除的待保存内容、文件和工具变更预览。
- 本地保存、远端推送、工具更新分别控制，默认仅本地保存。CLI 支持选择性提交、版本 Plan/Apply、完整新文件 Diff 和独立远端推送。
- 未选的暂存与未保存改动保留；隔离环境合并远端，重叠改动或过期预览停止操作。推送无需先清空无关能力的本地改动。
- 已恢复的设备仅快进或推送已有版本时，无需先配置版本作者；创建新版本或合并提交仍使用实际 Git 作者信息。
- 自动更新工具使用已保存快照；选择性保存只投影本次所选已保存能力，工具侧编辑会阻止未经审查的自动覆盖。
- 提交结果提供版本哈希、远端分支、所选与排除的能力，以及工具变更详情；管理 Skill 文档同步更新。

## 当前限制

- Codex、Claude Code 官方插件缓存仍仅扫描展示，不支持完整导入与跨工具同步。
- 工具侧修改不会自动反向导入；仍需用户审查并确认。
- 重叠的本地与远端修改需要先处理冲突；不会强制覆盖或自动丢弃未保存内容。
- 管理 Skill 需要单独手动复制，安装包不自动生成工具技能或规则。Windows 和 Ubuntu 安装包均包含界面及 CLI。
