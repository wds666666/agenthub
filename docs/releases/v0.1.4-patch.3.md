# AgentHub 0.1.4 补丁 3

标签：`v0.1.4-patch.3`。程序与安装包版本保持 `0.1.4`。

## 已实现与修复

- 首次使用可以从 GitHub 或自建 Git／Gitea 恢复已有 AgentHub 库，填写仓库地址并认证即可下载能力和版本历史；也可以创建空库或从本机工具导入。恢复不会上传或自动修改工具资源。
- 恢复前验证仓库结构、分支与历史，已有数据不会被覆盖；下载或切换中断可在下次启动恢复。重新安装沿用原库，丢失本机索引时可从有效库内容重建。
- 修复 Windows 接收远端更新时 Git 不接受系统规范化路径前缀的问题，保留盘符、网络共享及中文路径。
- 新设备接收远端更新支持验证后的快进，无需为了接收更新配置版本作者；两边都有提交时继续合并，冲突保留本地版本。
- 自动检查 Agents、Cursor、Codex、Claude Code 中已有 Skill 的内容变化，在导航和对应条目显示红点，打开即可选择导入。完整比较正文及支持文件，忽略环境与缓存目录。
- 检查最多每两分钟一次，隐藏窗口停止检查；按文件元数据缓存摘要，每三十分钟重新读取内容兜底。1000 个库内 Skill 加四个工具各 1000 份副本的本地样本：首次检查约 790 毫秒，缓存后的元数据检查约 121 毫秒。
- 导入修改后的副本保留原项，并作为独立条目加入库；查看提示不会自动导入、提交或推送。新发现的 Skill 仍通过“扫描并导入”添加。
- 完善重装清理：清理安装程序拥有的旧资源，保留能力库、版本、本机状态、密钥和用户文件。Windows 以资源清单及旧文件校验值确认归属，保留用户修改过的文件。
- 更新管理 Skill 的恢复操作、安装与同步说明；Windows 一次安装包含界面、CLI 和管理 Skill，便携 ZIP 同样完整。

## 验证

Ubuntu 本地核心与前端测试、Chromium／WebKit 桌面及窄窗口交互、真实 Git HTTPS 认证与恢复集成测试通过。Ubuntu 安装包已验证替换、重装和卸载保留用户数据。发行版复用本标签的双平台 Actions 产物，并要求 Windows 原生安装、升级、卸载及命令发现检查通过。

## 尚未完成

- 完整 Plugin 导入与工具同步；Codex、Claude Code 官方插件缓存当前仅扫描展示。

## 下载

Windows 优先使用 `AgentHub_0.1.4_x64-setup.exe`，包含界面、CLI 和 Skill，无需另装 CLI；也提供 MSI 和 `AgentHub_0.1.4_windows-x64-portable.zip`。Ubuntu 使用 `.deb`。运行前安装系统 Git；便携 Windows 版还需 WebView2。校验文件见 `SHA256SUMS.windows.txt` 和 `SHA256SUMS.linux.txt`。
