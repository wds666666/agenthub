# AgentHub v0.1.5-patch.3

程序版本保持 0.1.5，本次补丁完善桌面后台运行和按范围自动同步。

## 已实现

- 同步范围支持“本类全部能力（含以后新增）”；只有明确开启的工具和类别接收新增能力。
- 导入、编辑及外部修改库内容后，按本机设置立即或定时同步；连续编辑合并处理，暂停状态可保存。
- 关闭窗口可选择退出或托盘后台运行；托盘提供打开窗口、立即检查并同步、暂停／恢复和退出，重复启动打开现有窗口。托盘不可用时保持窗口可访问。
- 设置可分别调整工具变更检查频率和库到工具的同步频率；工具侧修改只提示，不自动反向导入，宿主漂移仍阻止自动覆盖。
- 安装包内置管理 Skill，桌面首次启动、升级及主动扫描时维护到 AgentHub 库；已知旧版先备份，用户修改或未知同名内容报告冲突。不自动提交或推送。
- 安装不直接向工具目录添加技能或规则；管理 Skill 仅按已启用范围分发。普通启动不会因为工具副本被删除就重新补齐。
- 同步记录显示触发原因、来源状态及实际新增、更新、删除的能力；旧记录显示触发原因未知。
- 文件监听、元数据缓存及统一后台调度减少重复扫描，状态查询不重新扫描全库。

## 验证与安装

- Ubuntu 本地核心、界面及真实桌面测试通过，WebKit 界面测试 31 项通过；覆盖后台同步、单实例、管理 Skill 更新冲突、暂停、漂移保护及安装升级数据保留。
- 1,000 个 Skill 本地测试首次扫描约 0.83 秒；性能随设备及文件体积变化。
- 发布复用通过 Windows、Ubuntu 构建及对应安装检查的同一提交产物。
- Windows 完整安装包、便携 ZIP 及 Ubuntu `.deb` 均包含桌面与 CLI；普通用户无需另装 CLI。升级前请退出旧版，包括托盘进程。

## 当前限制

- 官方管理的 Codex、Claude Code 插件缓存仍受保护，不支持完整插件同步。
- 不提供开机自启动或浮动小窗；Ubuntu 后台运行需要桌面环境支持系统托盘。
- 远端 Git 同步和工具分发仍是不同操作；此补丁不增加定时拉取或推送远端的行为。
- Windows 由云端完成编译与安装检查；本轮交互和后台运行人工验收在 Ubuntu 完成。
