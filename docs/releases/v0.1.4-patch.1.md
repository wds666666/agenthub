# AgentHub 0.1.4 补丁 1

标签：`v0.1.4-patch.1`。程序与安装包版本保持 `0.1.4`。

## 已实现与修复

- GitHub、自建 Git／Gitea 的界面令牌登录。本机加密保存仓库凭据，界面与 CLI 共用；支持重新登录、失败后重试和删除保存的凭据。
- 仓库状态区分仅保存地址、读取已验证、同步成功和失败。保存版本后先获取并合并远端，再上传；冲突保留本地提交，不强制覆盖。
- 修复导入列表连续点击后显示空白；按来源和类别选择，切换保留选择。Skills 只发现全局 Skills 目录的第一级，内部资源随父技能导入。
- 导入忽略 `.venv`、虚拟环境、`node_modules`、缓存和 `.git`，保留技能说明、脚本、依赖清单及资源。不能导入的文件提前说明原因，失败提供具体错误。
- 同步与工具清理的恢复副本保留环境内的符号链接，不跟随链接复制外部文件。修正 Git 忽略规则，确保技能内部的 `.gitignore` 等内容正常保存。
- 一次安装提供界面、CLI 和管理 Skill；更新认证、迁移和冲突处理说明。Windows 另提供完整便携 ZIP。
- 普通推送只做轻量检查；本地验证通过后创建标签，才触发云端构建。发行版复用已成功的双平台产物。

## 验证

Ubuntu 本地构建已测试；48 项 Rust 测试、14 项前端测试、20 项浏览器用例，以及真实 Git HTTPS 集成测试通过。用户已验证 Gitea；独立私有 GitHub 测试仓库通过登录、上传、双设备合并、自动推送、冲突保留与解决、凭据删除等 10 项检查。Windows 构建与安装检查在本标签的 Actions 中执行。

## 尚未完成

- 完整 Plugin 导入与工具同步；Codex、Claude Code 官方插件缓存当前仅扫描展示。
- 浏览器 OAuth 登录、可视化冲突处理、后台实时跨设备同步。当前使用访问令牌、系统 Git 凭据或 SSH，冲突可由 Agent 按管理 Skill 协助处理，内容取舍仍需用户决定。
- CLI 尚未覆盖全部桌面操作；多选导入、批量删除、工具清理、重置及自动同步范围配置使用界面。
- macOS、ARM64、AppImage、浏览器完整版及 Windows 代码签名。

## 下载

Windows 优先使用 `AgentHub_0.1.4_x64-setup.exe`（包含界面、CLI 与 Skill，无需另装 CLI），也提供 MSI 和 `AgentHub_0.1.4_windows-x64-portable.zip`。Ubuntu 使用 `.deb`。使用前安装系统 Git；便携 Windows 版还需 WebView2。校验文件见 `SHA256SUMS.windows.txt` 和 `SHA256SUMS.linux.txt`。
