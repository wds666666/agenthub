# AgentHub 0.1.3

本次发行版基于当前最新实现，重新整理发布内容与支持范围。功能延续 0.1.2；本次没有新增插件支持。后续默认只提供 GitHub Actions 临时构建产物，未经用户明确同意不会创建发行版。

## 已实现

- **全局能力库**：管理用户级 Skills、MCP 配置及 Rules；支持从共享 Agents、Cursor、Codex、Claude Code 的已支持全局位置扫描导入，不扫描项目目录。
- **按来源导入**：固定显示全部支持的来源，可跨来源、类别选择；显示扫描数、可选新内容数和去重后的预计导入数。相同内容不会重复导入。
- **能力库管理**：详情预览、搜索、规则创建/编辑及 Markdown 导入；支持跨类别多选、按当前结果或类别快速选择、批量删除。批量删除前确认清单，保留本机恢复副本，之后统一执行已启用的自动同步。
- **工具同步**：Skills、MCP、Rules 按目标和所选范围生成变更预览，确认后写入。实际写入先备份、校验，失败尝试恢复；支持同步记录和事务回滚。共享 Agents 仅管理 Skills。
- **自动同步**：按用户启用的目标与范围，在 AgentHub 内容变更后执行；不是后台文件监视器，不会自动导入工具中的修改。
- **重置**：设置中输入 `AGENTHUB` 确认，将完整旧数据移至私有恢复目录，再返回导入向导；不会清空宿主工具。
- **工具资源清理**：按当前工具选中可删除资源、快速清理并显示备份位置；删除前列出清单并要求确认。官方管理的受保护插件、市场与缓存不直接删除。
- **本地版本与 Git 远端**：保存版本、查看状态/差异/历史，连接专用 HTTPS/SSH 仓库及分支。每次保存先提交本机，再获取并合并远端，最后推送；可手动同步及断开连接。推送不会强制覆盖，遇到并发更新会有限重试。
- **设备与内容分离**：Git 保存能力内容及版本；SQLite、本机目标与自动同步设置、密钥、恢复副本、日志和投影留在本机。上传前检查历史中的不允许路径和可识别的 JSON 明文凭据。
- **桌面构建**：提供 Windows x64 安装版/便携版/CLI，以及 Ubuntu x64 `.deb`、桌面程序和 CLI；包含 SHA-256 校验文件。Windows 桌面及应用启动的 Git 子进程采用无终端窗口方式，Git 认证不弹交互窗口。

## 尚未完成及当前限制

- **完整 Plugin 导入与宿主同步尚未完成**：Codex、Claude Code 官方安装的市场/缓存插件目前只扫描展示，不能从缓存导入，也不能同步回这些工具。Claude 本地插件有受限的整包导入逻辑，Cursor 本地目录有基础文件投影路径；这不代表插件支持已完整落地。插件在库中出现或可预览，也不代表能在目标工具中安装、注册或使用。
- **没有应用内 Git 登录授权流程**：使用系统 Git 已保存的凭据或 SSH Agent。姓名、邮箱仅标识版本作者。读取仓库成功不保证有推送权限，凭据失效需要在系统中处理。
- **没有可视化合并冲突处理**：同一资源冲突时停止并保留本地版本，需要用户协调/处理后重试。远端同步需要先保存本地变更，不会自动放弃修改。
- **没有后台多设备实时同步**：保存版本后尝试远端同步，其他设备通过“同步远端”接收；接收后需单独选择并预览同步到工具。各设备自行配置本机可执行程序和凭据。
- **不是完整的凭据防泄漏系统**：不能保证识别任意 Markdown、插件资源或二进制中的秘密，也不保证所有 MCP 占位符都由各工具自动解析；共享仓库前仍需审查内容与历史。
- **浏览器完整版、GitHub Pages 部署未实现**：完整管理功能依赖本机桌面后端。
- **平台范围**：当前提供 Windows/Ubuntu x64 构建；没有 macOS、ARM64 或 AppImage 安装包。Windows 尚未进行 Authenticode 签名，系统可能提示未知发布者。

## 安装与验证

Windows 下载 `AgentHub_0.1.3_x64-setup.exe` 或 MSI，便携版另行提供。需要系统 Git；便携版还需要可用的 WebView2 运行时。Ubuntu 安装 `.deb`，或在具备所需系统依赖的环境运行桌面可执行文件。

下载后对照 `SHA256SUMS.windows.txt` / `SHA256SUMS.linux.txt` 校验。GitHub Actions 会执行前端测试、Rust 核心测试及平台构建验证；Windows 打包检查桌面 GUI 子系统，Ubuntu 检查格式与 Clippy。构建成功不等同于已验证所有宿主工具版本或所有插件兼容性。
