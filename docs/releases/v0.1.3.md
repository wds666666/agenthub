# AgentHub v0.1.3

当前版本提供 Windows x64 与 Ubuntu x64。本次统一安装、便携分发和 Agent 操作指引，重新构建并替换同一版本；标签 `v0.1.3` 指向本次构建提交。

## 已实现

- 一次安装同时获得界面、同版本 CLI 和管理 Skill。Windows NSIS/MSI 配置当前用户的命令路径，卸载移除安装器添加的路径；旧进程环境下，Skill 可通过安装记录定位 CLI。
- Windows 完整便携 ZIP 包含界面、CLI、命令定位脚本和管理 Skill；Ubuntu `.deb` 同时安装 CLI 与 Skill。独立 CLI 下载为可选项。
- Agent CLI 支持 `validate --json` 内容校验和 `plan --selection` 范围预览。管理 Skill 增补备份迁移、格式、恢复与基于原生 Git 的冲突处理步骤。
- 按来源和类别选择导入全局 Skills、MCP、规则，保留选择并去重。
- 能力库搜索、预览、规则编辑及多选批量删除；删除前确认并保留本机恢复副本。
- 按目标和范围预览同步，实际写入先备份、验证，支持恢复及用户启用的自动同步。
- 工具资源快速清理、AgentHub 重置，操作前明确提示影响范围；受保护目录保留。
- Git 本地版本与多设备同步：先保存本机，再获取并合并远端，最后推送。设备设置、密钥、备份和日志留在本机。

## 尚未完成

- 完整 Plugin 导入与工具同步。Codex、Claude Code 官方插件缓存目前仅扫描展示；已有的本地插件基础路径不代表完整支持。
- 应用内 Git 登录、可视化冲突处理及后台实时多设备同步。当前依赖系统 Git 凭据或 SSH Agent；Agent 可按 Skill 协助合并冲突，矛盾的内容仍需用户决定。
- CLI 尚未覆盖后续多选导入、批量删除、工具清理、重置和自动同步范围配置，这些操作使用桌面界面。管理 Skill 需要复制到所用工具的用户级 Skills 目录才能被加载。
- 浏览器完整版、macOS、ARM64、AppImage 及 Windows 代码签名。任意文件中的秘密也无法保证全部自动识别。

## 下载与使用

Windows 优先使用 `AgentHub_0.1.3_x64-setup.exe`，或使用 MSI；**无需再安装独立 CLI**。便携版使用 `AgentHub_0.1.3_windows-x64-portable.zip` 并完整解压。Ubuntu 使用 `.deb`。使用前安装系统 Git；Windows 便携版还需要 WebView2。下载后对照 `SHA256SUMS.windows.txt` 或 `SHA256SUMS.linux.txt` 校验。

详见 [项目首页](https://github.com/wds666666/agenthub#readme) 和 [工作流规则](https://github.com/wds666666/agenthub/blob/main/docs/workflow.md)。后续默认只提供 Actions 临时产物；未经明确同意不创建发行版，也不改版本号。
