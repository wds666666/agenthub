# AgentHub 0.1.5

标签、程序和安装包版本：`v0.1.5` / `0.1.5`。

## 本次更新

- 新建规则只保存到 AgentHub。规则可逐条选择，明确开启自动同步后，后续编辑才会同步到工具。
- 默认保留工具自有内容，只添加或覆盖勾选的能力；取消选择或删除库内容不会自动删除工具副本。设置也提供“替换所选类别”，执行前展示删除项。旧自动同步配置暂停，保留选择供用户重新确认。
- GitHub／Gitea 更新先进入本地能力库；工具同步使用本机保存的选择。同步保持预览、备份、验证与失败回滚，配置无法解析或发生并发修改时停止写入。
- 统一 Skills、MCP、Rules 和 Plugins 的内容比较与导入去重。相同内容标记“库中已有”，后端拦截重复导入；同名但不同配置标记变化。识别生成的规则容器，避免反向导入造成重复。
- 版本记录按能力展示变动，也可查看文件明细。增加“放弃未保存更改”和“使用远端内容”：先预览并明确确认，完整备份后替换库内容，保留历史、本机状态和工具文件；远端或本地在预览后变化时拒绝执行。
- 修复 Windows 路径与 Git CRLF 换行转换造成的内容比较、版本恢复误报，忽略 `.venv` 等运行目录。
- Windows 安装包与便携包均包含 UI 和 CLI。管理 Skill 改为手动复制，不再自动安装 Skill 或工具规则；升级保留用户修改过的旧管理 Skill 文件和 AgentHub 数据。
- 完善管理 Skill 的同步范围、认证、迁移、冲突与版本恢复说明。

## 验证

Ubuntu 本地核心、前端及 Chromium／WebKit 交互测试通过；真实 HTTPS Git 测试覆盖认证、双设备合并、远端恢复、过期预览拒绝和失败回滚。发行产物必须通过本标签的双平台 Actions 检查，包括 Ubuntu 重装与卸载、Windows 安装升级卸载及 CLI 命令发现验证。

## 仍有限制

- Codex、Claude Code 官方插件缓存仍仅扫描展示，不支持作为完整插件导入及同步；其他插件按当前适配格式处理。
- 工具侧变化不会自动回收进库；Skill 变化提醒后仍需用户选择导入。新增资源通过扫描导入。
- Git 内容冲突不自动决定取舍，需用户或管理 Skill 协助处理。工具同步选择与记录保存在本机，不由远端覆盖。
- CLI 尚未覆盖所有桌面管理操作。macOS、ARM64、AppImage、浏览器完整版及 Windows 代码签名尚未提供。

## 下载与使用

Windows 优先下载 `AgentHub_0.1.5_x64-setup.exe`，无需再安装 CLI；另提供 MSI 和完整便携 ZIP。Ubuntu 使用 `AgentHub_0.1.5_amd64.deb`，也提供独立可执行文件。系统需安装 Git；Windows 便携版需 WebView2。

管理 Skill 位于本标签的 [skills/agenthub-manager](../../skills/agenthub-manager)，按 [手动安装说明](../../skills/agenthub-manager/references/installation.md) 复制。文件校验值见发行附件 `SHA256SUMS.windows.txt` 和 `SHA256SUMS.linux.txt`。
