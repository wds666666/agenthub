# AgentHub v0.1.5-patch.1

程序版本保持 0.1.5，本次为修复补丁。

## 已修复

- Cursor 旧版规则容器缺少 rules 目录时，不再导致工具资源页面全部为空。
- 扫描按来源和能力类别隔离错误；损坏配置和错误路径显示为不可操作，正常类别继续显示。
- 同名普通插件不再误认为 AgentHub 规则容器，规则同步拒绝覆盖未知容器。
- 使用云端内容的预览按 Git 换行符和文件属性规则比较，避免 Windows CRLF 导致大量未修改 Skills 被误报。
- 恢复确认弹窗限制在窗口内，长列表可滚动，标题与操作按钮保持可见；确认输入不会被按钮区遮挡。

## 验证

- 本地 83 项核心测试、19 项界面测试、22 项 Chromium 浏览器测试通过。
- 覆盖旧容器残留、损坏配置、后端导入与清理拦截、Windows CRLF、二进制属性及恢复事务校验。
- Windows 和 Ubuntu 构建及安装检查通过后发布；安装包仍包含界面与 CLI。

## 当前限制

- 官方管理的 Codex、Claude Code 插件缓存仍受保护，不支持完整插件同步。
- 管理 Skill 需按仓库文档手动安装，安装包不会自动向工具添加 Skill 或规则。
- 本地 WebKit 测试因系统缺少依赖未运行；云端 Ubuntu 工作流执行对应浏览器测试。
